医疗输液监控系统
硬件适配：数码管（显示液量）、LED（状态指示）、蜂鸣器（报警） 
1. 语言基础（液量检测）
	任务：编写液滴脉冲计数程序（P3.2模拟液滴传感器） 
	要求：每10滴液量在P1口LED显示二进制累加值 
2. I/O接口设计（参数设置）
	任务：矩阵键盘设置输液总量（50-500ml） 
	开发板实现： 
	数码管实时显示"Set:XXXml" 
	LED灯环指示设置进度（每50ml亮1个LED） 
3. 定时器应用（滴速控制）
	任务：定时器1监控滴速异常（正常1-2滴/秒） 
	要求：滴速超限时P2.0口LED闪烁（仿真验证中断服务程序）

	外部中断0响应气泡报警（按键K1模拟）
